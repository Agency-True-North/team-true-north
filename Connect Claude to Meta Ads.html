01 / What This Gives You

Ads Manager was built for agencies with a full-time person staring at it. You have twenty minutes between dinner and bedtime. After this, you ask Claude how the ads did and it reads the numbers for you.

Spend, leads, cost per lead, which ad set is winning and which one is quietly eating the budget. Claude pulls it live from your account and tells you in plain words. When you are ready to build, it drafts the copy in your voice and walks you through the launch step by step, inside your existing campaign where Meta has already learned who to show it to.

Under the hood, this installs a small connector on your computer, the same one Shannon runs. It renews its own key, retries when Meta is being Meta, and translates Meta's error codes into sentences a human can act on.

02 / Before You Start

Three things, then you are ready.

1

Your Claude workspace is set up

You finished the Claude Setup Guide, so you have a Claude folder open in VS Code with a CLAUDE.md file in it. If not, do that first.

2

Your ad account lives inside a Meta Business Portfolio

That is the business.facebook.com side of Meta, with your ad account and your page inside it. The Meta Ads Setup Guide builds it in sections 02 and 03. Claude asks about this first and sends you there if you need it.

3

Twenty-five uninterrupted minutes and your Facebook password

Meta asks for your password at two points along the way. Have it handy. Claude waits for you at every click, but Meta logs you out if you wander off too long.

04 / What Claude Will Ask You For

Three things live inside Meta that only you can do. Claude cues each one when it is time, one click per message, and explains what each one is for. This section is here so none of it surprises you.

1

Create a private Meta app

Meta only lets software into an ad account through something it calls an app. Yours is private, just a door with your name on it. Nobody else ever sees it, and it never needs to be published or reviewed.

The clicks Claude will walk you throughdevelopers.facebook.com → My Apps → Create App → choose the option about Marketing API or managing ads → name it Claude Ads → pick your Business Portfolio → Create app.
2

Copy the App ID and App Secret

Both sit on one screen: App settings → Basic. The App ID is a long number and is not secret; you paste it into the chat. The App Secret is hidden behind a Show button and is secret; it goes into a file, never the chat.

3

Generate a key that never expires

In Business Settings you add a "system user" named Claude, give it your app, your ad account, and your page, and generate a token set to Never expire. One time, and you never think about it again.

The clicks Claude will walk you throughbusiness.facebook.com/settings → Users → System users → Add → name Claude, role Admin → Assign assets (app, ad account, page) → Generate new token → app Claude Ads → expiration Never → tick ads_management, ads_read, business_management, pages_show_list, pages_read_engagement → Generate.
Secrets go into a file, never into the chat

Claude has already made a file in your Claude folder called .mcp.json with blank spots labeled PASTE_YOUR_APP_SECRET_HERE and PASTE_YOUR_ACCESS_TOKEN_HERE. You click that file in VS Code, paste over those words (keep the quote marks on both sides), and save. Claude checks the blanks are filled without ever reading them out loud. That file stays on your computer and is kept out of any backups.

If Meta won't offer "Never"

Some portfolios have to be verified before Meta allows a never-expiring key. Claude switches you to the backup route: a personal key from Meta's Graph API Explorer. The connector trades it for a two-month key and renews it every week while you use it. The only things that kill it are a Facebook password change or two months of not using it, and renewing takes two minutes with Claude.

05 / The Restart

Before the restart, Claude runs a check that proves your key is valid, has the ad permissions, and can see your ad account by name. Only after that passes does it ask you to do this:

1

Reload the window

Press Cmd+Shift+P on Mac or Ctrl+Shift+P on Windows, type Reload Window, press Enter.

2

Approve the connector

Open the Claude panel. A small prompt may say a new MCP server named meta-ads was found in this project. Choose the option that uses it.

3

Paste the box once more

Start a new conversation and paste the Section 03 box again. Claude sees the setup is finished, runs the live test, and tells you the name of the ad account it is connected to.

07 / Rules That Keep Your Ad Account Safe

This connection can spend real money. Claude follows these, and you should hold it to them.

Rule 1Reading is free. Changing needs a yes.

Claude never creates, edits, pauses, launches, or changes a budget unless you say yes to that exact action in that conversation. Before it touches a budget it says the dollar amount back to you.

Rule 2One campaign. New ad sets inside it.

Meta learns who to show your ads to inside a campaign. Starting a new campaign for every test throws that learning away. Claude adds ad sets to the campaign you already have, each with its own budget, so a new test never starves the one that is working.

Rule 3The key is yours. Treat it like a password.

It lives in one file on your computer and nowhere else. If you ever think it leaked, go to Business Settings, open the Claude system user, and revoke the token. Then paste the box again and Claude helps you make a new one.

08 / Troubleshooting

Claude has this same table and will work through it with you. Check here before assuming anything is broken.

"No ad account is attached"The Claude system user never got your ad accountBusiness Settings → System users → Claude → Assign assets → Ad accounts → tick yours, full control. No new key needed.

The download step failsA hiccup reaching the team siteTell Claude: "Try the downloads again, and if they still fail, use raw.githubusercontent.com/Agency-True-North/team-true-north/main/ instead of the team site address."
